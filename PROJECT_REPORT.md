# Project Report – HR Analytics

## Objective
Analyze employee workforce characteristics and attrition patterns to support evidence-based HR review.

## Tools
MS SQL Server, MS Excel, Power BI, Python (for reproducible preprocessing and chart generation).

## Workflow
1. Inspect the raw CSV and profile data types, missing values and duplicates.
2. Apply transparent cleaning rules and export a cleaned CSV.
3. Load cleaned records into SQL Server.
4. Answer HR business questions using 50 SQL queries.
5. Prepare Excel summary sheets and visualizations.
6. Build a Power BI report using the provided measures and layout guide.
7. Communicate findings with limitations and recommendations for validation.

## Deliverables
See repository README and folder structure.

## Professional reflection
A strong analyst should be able to explain why each cleaning decision was made, how each metric is calculated, what the SQL query returns, and what limitations apply. Re-run the project and customize at least two analyses before presenting it as personal work.
